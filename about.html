ASTO

A word game by Max Rowe

What this is

ASTO is a word puzzle game inspired by Connections. Sixteen tiles hide four analogy sets: A is to B as C is to D (A:B::C:D). It is Max’s capstone project for a class on multi-agent AI development.

How the puzzles are made

The puzzles are generated by an AI authoring pipeline that Max built, prompted, and continually edits. It consists of a team of specialized agents that write, check, and critique each board based on parameters set by Max to make a game that is challenging, delightful, and fair.

Every published puzzle has been played by Max before release. Max judges the quality of the puzzle, makes changes where necessary, and sincerely hopes you will enjoy.
