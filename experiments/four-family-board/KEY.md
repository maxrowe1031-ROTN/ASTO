# The key — open only after playing both boards

**Board A (`exp-kitchen-a`) is the four-family board.** One set per family:

| tier | set | family (Bejar) |
|---|---|---|
| green | Cucumber : Pickle :: Cabbage : Sauerkraut | 3e SIMILAR · Conversion — the pipeline's home turf, kept as the easy on-ramp |
| yellow | Nutmeg : Grater :: Pepper : Grinder | 7g CASE · Object:Instrument (violin:bow) — never produced by the pipeline |
| red | Morning : Breakfast :: Evening : Supper | 9f SPACE-TIME · Time:Activity (summer:harvest) |
| black | Sizzle : Frying :: Whistle : Boiling | 10a REFERENCE · Sign:Significant (siren:danger) — never produced |

Tiers are ordered by how subtle the *family* is to recognise, not by word rarity — the
"principled difficulty ladder" hypothesis.

**Board B (`exp-kitchen-b`) is the control** — four sets, all CAUSE-PURPOSE/Conversion
"one thing becomes another", which is what ~80% of the pipeline's output has been:
baked (dough:bread), dairy (milk:cheese), roasted seed (kernel:popcorn), slow method
(simmer:stew).

**What to compare, having played both:** which board's *reveals* felt better? On B, did
knowing one set's trick make the others feel like sorting? On A, did the different
kinds of question feel varied or incoherent? Either answer is a good outcome — the
point was to feel it, not to be right.
