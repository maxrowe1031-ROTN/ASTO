# Round 2 key — open only after playing both night boards

**Board B (`exp-night-b`) is the test board** — one arrowed set as the on-ramp, then
three genuinely **arrowless** relationships, the kind ASTO has never used:

| tier | set | relation kind |
|---|---|---|
| green | Firefly : Glow :: Cricket : Chirp | arrowed anchor — creature emits its signal |
| yellow | Constellation : Orion :: Planet : Venus | **class : named individual** (1e) — pure membership, no time in it |
| red | Moon : Crater :: Comet : Tail | **static part-whole** (2a) — the feature is just *there* |
| black | Shadow : Weight :: Ghost : Footprint | **distinctive absence** (2i, tundra:tree) — the relation is what it *lacks* |

**Board A (`exp-night-a`) is the control** — all four sets arrowed, "one thing then/
becomes/leaves another", i.e. the texture ~80% of pipeline output has always had:
sends out (lighthouse:beam), hatched from (cocoon:moth), fades into (ember:ash),
leaves behind by morning (night:dew). Deliberately written as evocatively as possible
— if the arrow hypothesis only holds against drab controls, it isn't a real effect.

Note the flip from round 1: last time A was the test board. If you guessed by letter,
it didn't help you.

**What round 2 is asking:** on Board B, did the category set, the feature set, and the
absence set *feel* like different kinds of question — or did it all blur into "stuff
about the night sky" again? On Board A, did the four arrowed reveals collapse into one
trick (round 1's demotion pattern), even though each is individually poetic? The
hypothesis (arrow vs arrowless is the felt variable — n=1, NOT law) predicts B feels
varied and A collapses. If the opposite happens, or nothing separates them, the
hypothesis is wrong and that is a fine outcome.
