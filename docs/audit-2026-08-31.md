# Pipeline cost audit — 2026-08-31

> The raw numbers behind ASTO's Assignment 10 audit. Every figure here was read off
> `studio/runs/` on 2026-08-31, not estimated. The script that produces it is at the
> bottom of this file, so any claim in the submission can be re-derived from disk.

**Scope, stated plainly:** these are **Anthropic API costs incurred by the `studio/`
pipeline only** — the eleven agents that author and evaluate boards. They do **not**
include the Claude Code sessions that built the game and the Studio, which are the larger
number and are not measured here. Class 12's point that human review hours dominate the
bill applies to both and is not priced in either.

**Where the numbers come from.** `budget.js` charges every `llm.send()` on both the
success and failure paths, so a truncated or refused request costs exactly what it
actually cost. Each attempt's running total is persisted to
`studio/runs/<run>/attempts/<id>/attempt.json` under `usage.attempt`, stamped with the
`pricingVersion` and `effortProfile` that produced it. Per-stage figures are re-priced
from each stage's own `request.json` (`inputTokens` / `outputTokens`) against the rates
in `studio/pipeline-config.js`, because `budget.js` persists the running total rather
than a per-stage split.

**Prices used** (USD per million tokens, from `pipeline-config.js` `rates`,
`pricingVersion: 2026-08-02`): `claude-sonnet-5` — $3 in / $15 out ·
`claude-haiku-4-5` — $1 in / $5 out. Sonnet is listed at its standard rate rather than
the introductory one, deliberately: a cap computed from the cheaper price stops
enforcing the moment the intro period ends.

## Reading it

**One board costs $2.41 to publish, and $0.87 to attempt.** The gap is the human gate:
145 runs produced 51 published boards, so **roughly two of every three runs never
reached a player**. That is not waste — 44 were rejected on judgement and 53 were sent
back for revision. The $1.54 difference per board is the price of a review loop that can
say no.

**One stage is 45% of the bill.** `01-pair-author` cost $55.52 of $123.02. It runs at
`high` effort (the only stage that does), and it carries the most context of any stage —
all 36 controlled-vocabulary entries, the stance quotas, the register assignment and the
recently-published-words avoid-list. It is also the only stage that has ever truncated
itself out of a run: five themes died that way in one evening at ~$0.62 each (design.md
D-12), and the fix was an escalation retry that steps effort *down*, because what
overran the ceiling was thinking, not answer.

**The evaluators are cheap; the authors are not.** Stages 05–08 together — four
independent evaluators of a finished board — cost $37.73, less than `01` alone. The
cheapest of them, `05-analogy-validator`, runs on Haiku and costs $0.0037 a call: it is
a checker, priced as one. Nothing about the evaluation half of this pipeline is where
the money goes.

**The effort-profile series is not a cost-reduction curve, and should not be read as
one.** `lean-2` (2026-08-03) cut the mean attempt from $0.358 to $0.279 — **22%** — by
re-aiming per-stage effort from a measurement pass instead of a guess. Spend then rose
to $0.585 and $0.707 across the next two profiles, on purpose: `03` and `08` moved
Haiku → Sonnet for the taxonomy shakedown, `06` gained the cross-reading checklist, and
`09-glossary-author` was added. Cost went up because the pipeline started doing work it
had not been doing. The unexercised lever is still on the books as the **slim-down lap**
in `docs/backlog.md`: re-run the lean-2 measurement under the current profile, re-aim,
and revert the raised budget ceilings.

**A caveat on comparing profiles.** The buckets are not the same population — 112 of 197
attempts sit under `2026-08-05-cross-reading` and only 3 under `2026-08-03-lean`. The
profile string is stamped on every attempt precisely so boards built under two different
maps are never silently merged; small buckets should be read as indicative, not
measured.

**Four runs carry no usage record** (141 of 145): the two kitchen and two night
design experiments of 2026-08-04. They are hand-made mock runs driven through
`mock-transport.js`, which is priced at zero by design — no model was ever called.

## Reproducing it

Zero dependencies, Node ≥22. Save as `cost-report.mjs` in the repository root and run
`node cost-report.mjs`.

```js
// Reads studio/runs/ and reports what the pipeline spent. Zero dependencies.
// Run from the repo root:  node cost-report.mjs
import { readFileSync, readdirSync, existsSync, statSync } from 'node:fs';
import { join } from 'node:path';

const ROOT = 'studio/runs';
// From studio/pipeline-config.js `rates`, USD per million tokens.
const RATES = {
  'claude-sonnet-5': { in: 3, out: 15 },
  'claude-haiku-4-5-20251001': { in: 1, out: 5 },
  'mock-model': { in: 0, out: 0 },
};
const read = (p) => JSON.parse(readFileSync(p, 'utf8'));
const lines = (p) =>
  readFileSync(p, 'utf8').trim().split('\n').filter(Boolean)
    .map((l) => { try { return JSON.parse(l); } catch { return {}; } });

const totals = { runs: 0, attempts: 0, requests: 0, tokens: 0, cost: 0 };
const byStage = {}, byProfile = {}, byStatus = {}, byEvent = {};
let feedbackEvents = 0, feedbackRuns = 0;

const runDirs = readdirSync(ROOT).filter((e) => statSync(join(ROOT, e)).isDirectory());

for (const run of runDirs) {
  const dir = join(ROOT, run);
  const manifest = join(dir, 'manifest.json');
  if (existsSync(manifest)) {
    const status = read(manifest).status;
    byStatus[status] = (byStatus[status] ?? 0) + 1;
  }
  const decisions = join(dir, 'decisions.jsonl');
  if (existsSync(decisions)) {
    for (const e of lines(decisions)) byEvent[e.type] = (byEvent[e.type] ?? 0) + 1;
  }
  const feedback = join(dir, 'feedback.jsonl');
  if (existsSync(feedback)) { feedbackRuns++; feedbackEvents += lines(feedback).length; }

  const attemptsDir = join(dir, 'attempts');
  if (!existsSync(attemptsDir)) continue;
  let counted = false;

  for (const id of readdirSync(attemptsDir)) {
    const attemptFile = join(attemptsDir, id, 'attempt.json');
    if (existsSync(attemptFile)) {
      const attempt = read(attemptFile);
      const usage = attempt.usage?.attempt;
      if (usage) {
        counted = true;
        totals.attempts++;
        totals.requests += usage.requests ?? 0;
        totals.tokens += usage.tokens ?? 0;
        totals.cost += usage.costUsd ?? 0;
        const profile = attempt.effortProfile ?? '(unstamped)';
        byProfile[profile] ??= { attempts: 0, cost: 0 };
        byProfile[profile].attempts++;
        byProfile[profile].cost += usage.costUsd ?? 0;
      }
    }
    // Per-stage cost is priced from the stage request records, because
    // budget.js stores only the running attempt total, not a per-stage split.
    const stagesDir = join(attemptsDir, id, 'stages');
    if (!existsSync(stagesDir)) continue;
    for (const stage of readdirSync(stagesDir)) {
      const requestFile = join(stagesDir, stage, 'request.json');
      if (!existsSync(requestFile)) continue;      // 04a is a gate: no model, no request
      const request = read(requestFile);
      const rate = RATES[request.model] ?? RATES['claude-sonnet-5'];
      const input = request.inputTokens ?? 0, output = request.outputTokens ?? 0;
      byStage[stage] ??= { calls: 0, cost: 0, tokens: 0 };
      byStage[stage].calls++;
      byStage[stage].tokens += input + output;
      byStage[stage].cost += (input / 1e6) * rate.in + (output / 1e6) * rate.out;
    }
  }
  if (counted) totals.runs++;
}

const usd = (n) => '$' + n.toFixed(2);
const pct = (n, of) => ((n / of) * 100).toFixed(1) + '%';

console.log('TOTALS');
console.log(`  runs with usage   ${totals.runs} (${runDirs.length} run directories)`);
console.log(`  attempts          ${totals.attempts}`);
console.log(`  API requests      ${totals.requests}`);
console.log(`  tokens            ${totals.tokens.toLocaleString()}`);
console.log(`  spend             ${usd(totals.cost)}`);
console.log(`  mean per run      ${usd(totals.cost / totals.runs)}`);
console.log(`  per published     ${usd(totals.cost / byEvent.publish)}  (${byEvent.publish} publishes)`);

console.log('\nRUN STATUS');
for (const [k, v] of Object.entries(byStatus).sort((a, b) => b[1] - a[1])) {
  console.log(`  ${k.padEnd(18)}${String(v).padStart(4)}`);
}

console.log('\nDECISION EVENTS');
for (const [k, v] of Object.entries(byEvent).sort((a, b) => b[1] - a[1])) {
  console.log(`  ${k.padEnd(24)}${String(v).padStart(4)}`);
}
console.log(`  feedback events         ${String(feedbackEvents).padStart(4)}  (across ${feedbackRuns} runs)`);

console.log('\nCOST BY STAGE');
for (const [id, s] of Object.entries(byStage).sort((a, b) => b[1].cost - a[1].cost)) {
  console.log(
    `  ${id.padEnd(22)}${String(s.calls).padStart(4)} calls  ${usd(s.cost).padStart(8)}` +
    `  ${pct(s.cost, totals.cost).padStart(6)}  avg $${(s.cost / s.calls).toFixed(4)}` +
    `  ${(s.tokens / 1e6).toFixed(2)}M tok`,
  );
}

console.log('\nCOST BY EFFORT PROFILE  (chronological)');
for (const [id, p] of Object.entries(byProfile).sort()) {
  console.log(
    `  ${id.padEnd(32)}${String(p.attempts).padStart(4)} attempts  ` +
    `total ${usd(p.cost).padStart(8)}  mean $${(p.cost / p.attempts).toFixed(3)}`,
  );
}
```
